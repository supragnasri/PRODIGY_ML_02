# PRODIGY_ML_02

## Customer Segmentation using K-Means Clustering

### Objective
Segment retail store customers into groups based on Annual Income and Spending Score.

### Dataset
Mall Customers Dataset

### Technologies Used
- Python
- Pandas
- Scikit-Learn
- Streamlit

### Algorithm
K-Means Clustering

### Features
- Annual Income (k$)
- Spending Score (1-100)

### How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
```
